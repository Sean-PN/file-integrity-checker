## file-integrity-checker
- A simple Python script to create and verify file integrity baselines using cryptographic hashes (SHA256 or MD5). It allows users to generate hashes for multiple files, save them in a JSON file as a trusted baseline, and then later verify if any changes have been made by comparing current hashes to the saved baseline.
